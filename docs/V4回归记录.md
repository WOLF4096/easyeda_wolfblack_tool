## 1. 从 PCB 转原理图

| 项     | 内容                                                                               |
| :----- | :--------------------------------------------------------------------------------- |
| 入口   | 原理图页 →「狼黑工具 → 从 PCB 转原理图」                                           |
| 步骤   | 新建并绑定 PCB 的空白原理图 → 加载数据 → 匹配符号 → 构建源码 → 写入文档 → 关闭重开 |
| 结果   | **通过**。写入后重新打开，器件符号与引脚完整，位置未漂移                           |
| 关注点 | V4 下 COMPONENT 行缺属性时写入会「假成功但器件被丢弃」，本版已补齐                 |
| 备注   | 工程规模与器件数待补                                                               |

## 2. 生成物理网络（三种写回）

| 项     | 内容                                                                      |
| :----- | :------------------------------------------------------------------------ |
| 入口   | PCB 页 →「狼黑工具 → 网络 → 生成物理网络」                                |
| 步骤   | 计算拓扑 → 分别用「网表」「源码」「API」三种方式写入 → 每种都关闭重开核对 |
| 结果   | **通过**。三种写回方式均能把网络落到当前 PCB，重开文档后网络关系仍在      |
| 关注点 | 源码方式整份写回后，铜皮填充缓存可能需要重算（见下节已知问题）            |
| 备注   | 三种方式各自的网络数对比数据待补                                          |

## 3. 批量替换器件

| 项     | 内容                                                                                                                  |
| :----- | :-------------------------------------------------------------------------------------------------------------------- |
| 入口   | PCB 页 →「狼黑工具 → 器件 → 批量替换器件」                                                                            |
| 步骤   | 粘贴「位号 + C 编号」 → 获取 → 替换 → 关闭重开确认器件真的换了                                                        |
| 结果   | **通过**。器件被真正替换（不是只改了属性），原坐标与角度保持，库中无临时器件残留                                      |
| 关注点 | V4 的器件引用有两处，只改一处会出现「属性变了、器件没换」；删除临时器件会连带销毁器件定义，因此必须先写源码再删临时件 |
| 备注   | 替换前后的器件 uuid 对照待补                                                                                          |
