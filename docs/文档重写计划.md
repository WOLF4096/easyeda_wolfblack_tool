## 四、写作规则（避免写成技术文档）

### 4.1 README 的功能描述

- **每条 ≤32 个汉字**（含标点按 1 字算），超出就删形容词，不删动作。
- 必须回答"点一下得到什么"，不解释"怎么实现"。
- 禁用词（出现在功能描述里就算不合格）：`源码`、`API`、`网表行`、`图元`、`递归`、`并发`、`缓存`、`JSON`、`UUID`、`POURED`、`setDocumentSource`。
  - 例外：`网表`、`图元`、`铜皮`、`封装`、`位号`、`丝印` 属于 PCB 用户日常词，可以用。

**改写示例**（现有 → 目标）：

| 现有（技术向，超字数） | 改后（≤32 字） |
| :--- | :--- |
| 对比原理图与 PCB 的引脚网络差异，通过底层源码拼接的方式，自动在原理图中为缺失网络的引脚快速生成可视化导线连接。（57 字） | 比对 PCB 与原理图的引脚网络，自动为缺失的引脚补上带网络名的导线。（31 字） |
| 利用多边形碰撞、线段相交、内切圆检测等纯空间几何算法分析画布上铜箔与图元的实际接触，在无原理图状态下逆向推导并重构整个物理网络。（64 字） | 没有原理图也能用：按铜皮的实际接触关系，反推出整块板的网络。（29 字） |
| 自动对同规格图元进行聚类，输入新立创编号后并发调用商城 API 拉取最新参数，在保持原坐标与角度不变的前提下批量完成底层替换。（61 字） | 按位号批量换成新的立创器件，位置和角度都不动。（24 字） |

### 4.2 每个功能必须写全 4 段

README 与 About 的内容结构统一为：

1. **一句话**：这是什么、解决什么（就是 32 字简述）；
2. **怎么用**：入口在哪 → 选什么 → 点什么 → 看哪里（3~6 步，用"选中/点击/粘贴"这类动词开头）；
3. **会得到什么**：结果落在哪（画布 / 表格 / 文件 / 弹窗）；
4. **注意**：什么情况下会失败或需要先做什么（如"位号不能重复""先切到原理图页"）。

### 4.3 CHANGELOG 的用户向写法

四类标题固定：**新增 / 修复 / 优化 / 移除**。每行一句，动词开头，说现象不说根因。

| 技术向（保留在 `项目日志.md`） | 用户向（新的 CHANGELOG） |
| :--- | :--- |
| 修复 V4 下 `lib_Device.getByLcscIds()` 返回对象导致 `t.length > 0` 恒假 | 修复 V4 上批量替换器件提示"库里找不到器件"的问题 |
| 修复 COMPONENT 行缺 `attrs` 时 `setDocumentSource` 返回 true 但静默丢弃器件 | 修复 V4 上转原理图后只剩导线、器件符号不见的问题 |
| ESLint 复杂度门禁从带基线变成硬 0 | （不写进用户日志，属内部工程） |
| 源码模块 82 → 108、import 152 → 209 | （不写） |

**规则**：
- 纯内部重构（拆分模块、加门禁、改测试）**整条删除**，用户看不出区别的事不写；
- 同一次发布里同一功能的多个技术修复合并成一条；
- 版本小标题保留 `## v1.20.0（2026-10-22）`，下面用 `### 新增` 分节；某版没有某类就省掉该节；
- `v1.16.0` 及更早**原样保留**，一个字不改（你要求只动 1.16.0 之后）。

## 六、硬约束（执行时容易踩）

| 约束 | 说明 |
| :--- | :--- |
| 页面产物是单文件 IIFE | 改 `features.js` 后必须 `npm run build:iframe`，否则 About 页看不到新内容 |
| 行内 `onclick` 必须挂 `window` | About 目前用 `addEventListener`，若新增按钮不要写成 `onclick="..."`；`test/inlineHandlers.test.mjs` 会扫 HTML 与模板串 |
| 模块头五标签 | `features.js` 的 `@//exports/` 必须与真实导出一致 |
| `common.css` | 18 页共用，只能改 about 段；`.hidden` 保持最末、不加 `!important`；被 JS 查询的类名不能改 |
| 不要整份跑 prettier | 工作区 CRLF + 旧文件 4 空格，`.prettierrc` 是 useTabs + lf，会产生几千行假 diff |
| ESLint 门禁 | `features.js` 有 `max-lines: off` 豁免；`index.js` 是页面入口（400→1800 豁免），但函数仍限 80 行 |
| 32 字校验 | 中文按字符数算，用一个临时脚本统计，别靠感觉 |
