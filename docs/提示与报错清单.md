## 一、口径说明

| 类型     | 含义                                                                    | 落点               |
| -------- | ----------------------------------------------------------------------- | ------------------ |
| 吐司     | 宿主轻提示 `sys_Message.showToastMessage`                               | 编辑器右下角       |
| 横幅     | 宿主不可用时 `ui/toast` 的降级红条                                      | 页面顶部，3 秒消失 |
| 确认弹窗 | `sys_Dialog.showConfirmationMessage`（或 `ui/dialogs` 的 Promise 封装） | 编辑器模态框       |
| 遮罩     | 页面级 loading 遮罩 + 文案                                              | 面板中央           |
| 状态栏   | 页面底部/顶部状态文字与进度条                                           | 页面内             |
| 结果区   | 表格行状态、输出框、反馈行                                              | 页面内             |
| 日志面板 | `sys_Log.add` 写入 EDA 日志并打开底部面板                               | 编辑器底部         |
| 控制台   | 仅 `console.*`，用户通常看不见                                          | DevTools           |

级别约定：**成功** / **错误** / **警告** / **信息**；历史调用中的数字 `2` = 警告、`3` = 提醒（见 `ui/toast.js` 的 `TOAST_LEVEL`）。

## 十、汇总与观察

| 分类                   | 条目数     | 备注                                                     |
| ---------------------- | ---------- | -------------------------------------------------------- |
| 公共基础层（#1–8）     | 8          | 含降级通道与网表底层报错                                 |
| PCB 转换类（#9–39）    | 31         | 焊盘⇄过孔 2 条均为「无提示」；其余走吐司/日志            |
| PCB 导入类（#40–94）   | 55         | 导入 AD 网表用页内 `feedback` 而非吐司                   |
| PCB 网络类（#95–127）  | 33         | 生成物理网络以状态栏 + 遮罩为主                          |
| PCB 器件类（#128–163） | 36         | 位号查重只写日志面板；替换器件 1 条为「无提示」          |
| 原理图类（#164–214）   | 51         | 含赞赏弹窗、网表缓存五入口；引脚排序 1 条为「无提示」    |
| 工时统计（#215–254）   | 40         | 危险操作一律二次确认 + 遮罩                              |
| 关于（#255）           | 1          | 仅图片浮窗，无文案提示                                   |
| **合计**               | **255 条** | 其中有效提示 250 条，另有 5 条记录现有功能的「静默」行为 |

三点值得注意的现状：

1. **静默功能**：焊盘 ⇄ 过孔、引脚排序没有成功/失败提示，失败只落控制台；批量替换器件在「无有效图元」时也只打 `logger.warn`。
2. **提示通道不统一**：同属失败提示，导线/填充转换用数字级别 `2`（警告），导入 AD 网表用页内 `feedback`，生成物理网络用状态栏，位号查重用日志面板——用户在不同功能里看到的位置不一致。
3. **文案含实现细节**：如 `API更新完成，耗时 {t}秒，修改焊盘API存在Bug，待官方修复后启用`、`源码已写入，但器件没有生成：…建议新建一个空白原理图页后重新写入`，直接暴露平台缺陷与规避手段，属有意为之的「可诊断性设计」。
