## 重构任务计划

### 背景结论（已侦查确认）

- 项目零测试、零测试框架，需从 0 引入。
- 前端 18 个 CSS 各自定义 `:root` 变量，命名混乱（`--bg`/`--bg-color`/`--vscode-bg` 三种并存），`::-webkit-scrollbar` 在 15 个文件重复，按钮色值/尺寸不统一（`#0e639c` vs `#007acc` vs `--primary`）。
- 前端 JS 存在大量重复：V2/V3 版本判断（`startsWith('2.')`/`startsWith('3.')`）、网表读取写回（`getNetlistFile`/`setNetlist`/`pinInfoMap`/`.components`）在 10+ 文件重复。
- 18 个 HTML 有 9 个存在 tab/空格混用缩进。

### 任务 1：模块化拆分后端 EDA 逻辑

**目标**：让纯逻辑可脱离 `eda` 环境独立测试，明确模块边界。

- `src/js/autoWire/netlistParser.js` 已是纯函数，**保持不动**（它就是边界清晰的可测模块）。
- 确认 `src/js/common/apiConfig.js`（`loadApiConfig`）作为「EDA 取数」与「纯解析」的边界：它内部读 `eda.sys_Storage`，测试时用 mock `eda` 覆盖。
- 不新增后端模块（现有拆分已到位），仅补齐接口文档注释。

**边界划分**：
| 模块 | 职责 | 是否依赖 eda |
| :--- | :--- | :--- |
| `netlistParser.js` | 纯解析/比对 | 否（可测） |
| `apiConfig.js` | 读校准配置 | 是（mock 测） |
| `autoWire/index.js` | 编排 + EDA 调用 | 是 |

### 任务 2：编写 EDA 调用链路测试（node:test）

**方式**：`.mjs` 测试文件 + mock `globalThis.eda`，`node --test` 运行（已验证 `.mjs` 可 import 无 type 的 `.js` ESM，仅无害警告）。

**测试文件**（放 `test/` 目录，已加入 `.edaignore` 排除打包）：

1. `test/netlistParser.test.mjs` — 覆盖纯函数：
    - `formatSchematicNetlist`：V2 格式 / V3 格式（`components` 字段）/ 单器件 / 多器件 / 缺 props 跳过。
    - `formatPCBNetlist`：数组 / 单对象 / 非 Component 过滤。
    - `processNetlistData`：有网差异 / 无差异 / 空网名。
2. `test/apiConfig.test.mjs` — mock `eda.sys_Storage`：
    - 正常返回配置 → 解析 JSON。
    - 返回空 → 回退默认。
    - 返回非法 JSON → 回退默认并 warn。
    - `getExtensionUserConfig` 抛错 → 回退默认。
3. `test/edaParams.test.mjs` — **EDA 参数类型/取值/顺序校验**（核心）：
    - mock `eda.pcb_PrimitiveLine.create` / `pcb_PrimitiveArc.create` / `pcb_PrimitivePolyline.create` 等，断言调用参数顺序、类型、缩放后的数值。

**关键参数校验点**（会在测试断言 + 最终报告列出）：

- `pcb_PrimitiveVia.create(net, x*coordScale, y*coordScale, hole*scale, outer*scale, ...)` 坐标与尺寸的缩放倍率是否正确。
- `pcb_PrimitiveLine.create(net, layer, x1, y1, x2, y2, width, false)` 参数个数与类型。
- `pcb_PrimitiveArc.create(..., angle*angleScale, ...)` 圆弧角度缩放。
- `setNetlist('JLCEDA', json)` 写回参数。

**新增 npm script**：`"test": "node --test"`。

### 任务 3：抽取前端 V2/V3 + 网表公共模块

**新建 `iframe/js/common.js`**，封装：

- `isV3()` / `getEditorVersion()` — 统一版本判断。
- `getNetlist(page)` / `setNetlist(page, json)` — 统一网表读写（封装 `pcb_ManufactureData`/`sch_ManufactureData` 的 try-catch 回退）。

**替换调用点**（优先低风险、高重复的文件）：

- `CodeConvert.js`、`ImportBom.js`（isV3 + componentsMap）
- 其余文件视改动风险分批替换，**行为保持完全一致**。

**引入方式**：HTML `<head>` 先 `<script src="/iframe/js/common.js">`，再加载页面自身脚本（每个 HTML 需加一行引用）。
