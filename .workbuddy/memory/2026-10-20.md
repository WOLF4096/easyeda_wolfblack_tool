### 必须记住的关键发现（后续若接手优化，优先处理）
1. **反调试死循环（红线）**：`iframe/WorkingHours.html:1888` 有 `setInterval(() => { Function('debugger')(); }, 200)`，每 200ms 触发 debugger；同文件还覆盖 `window.console`、拦截 F12/Ctrl+U（1886-1887 行）。
2. **"假加密"导出**：WorkingHours.html 的"安全导出"把 AES-GCM 密钥 `k` 与密文 `ct` 一起明文内嵌 HTML，可被直接解密。
3. **版本号不一致**：package.json=1.1.1 / extension.json=1.16.0 / CHANGELOG=v1.16.0。
4. **死代码**：`src/index.ts` 的 `NetReplace()` 打开不存在的 `/iframe/NetReplace.html`（实际为 ModifyNet.html）。
5. **CDN 依赖**：ImportQrcode.html 等引用 cdn.jsdelivr.net 的 echarts/fflate，与本地 iframe/js 版本并存。
6. **零测试、无 CI**（无 .github 目录）。

## 项目改造（按用户 3 点要求，不破坏现有功能）

### 1. WorkingHours.html 加密轻量化 + 移除反调试
- 移除 3 处反调试代码：`Object.defineProperty(window,'console')`、keydown 拦截 F12/Ctrl+U、`setInterval(Function('debugger'),200)`。
- `encryptPayloadAES`（AES-GCM 真加密）改为 `packPayload`（GZIP 压缩 + SHA-256 校验和），占位符 `_C/_I/_K` → `_D/_H`，打开端改为「解压 + 校验 hash」。
- 数据流：`crypto.subtle.digest('SHA-256')` 两端一致；导出端用 FileReader 转 base64，打开端用 `btoa(String.fromCharCode(...))`。

### 2. 消除重复代码 + 边界处理
- 新建 `src/js/common/apiConfig.js` 导出 `loadApiConfig(defaultConfig, storageKey='APITest')`，WireConverter/PadViaConverter 复用。
- WireConverter 抽取公共 `_emitLinesFromPath()`，消除 `_convertPolyToWire` 与 `_convertRegionToWire` 场景A 的重复 while 循环。
- PadViaConverter 的 scale 计算加 `?? 1` 兜底（修复配置缺键时 NaN 的隐患）。

### 3. 目录组织
- 新建 `scripts/`（build.cmd，CRLF+ASCII）、`temp/`（.gitkeep，eslint 缓存）、`docs/`（项目评估报告.md）。
- `npm run build.cmd` → `scripts/build.cmd`（内容改为 `cd /d "%~dp0.."` 回根目录）；根目录 `.eslintcache` 删除。
- lint-staged eslint 加 `--cache-location temp/.eslintcache`；.eslintrc.js ignorePatterns 改 `/temp/`；.edaignore 加 `/temp/ /scripts/ /docs/ /.idea/ /.workbuddy/`；.gitignore 加 `/temp/*` + `!/temp/.gitkeep`。

### 验证结果
- `npm run build`（compile + 打 .eext）成功；v1.16.0.eext 包内 37 文件，不含 temp/docs/scripts/.workbuddy/.idea，含 WorkingHours.html + dist/index.js + extension.json。
- WorkingHours.html 主 script 块 vm.Script 语法检查通过。
- WireConverter.js 重构后 `_emitLinesFromPath` 3 处（1 定义 + 2 调用）、`while (i<arr.length)` 仅剩 1 处。
