  （原生 ESM，18 个 HTML 各改一行）；不通过走通道 B（esbuild 按页打包成单文件 IIFE，HTML 不动）。
  **两种通道的源码目录完全一致**，只是 import 由谁解析。
- 目标结构：`iframe/js/{core,ui,pcb,sch,format,project}/**` + `app/<page-kebab>/**`，约 91 个文件
  （平均 148 行）；分层 `app → pcb|sch|format|project → ui → core`，禁止反向与循环（`check:deps` 守）。

  切勿放 `/backup/`）。备份含 18 个 app js + common.js + 18 个 html + MANIFEST(sha256) + RESTORE.md。
- 交付标准：模块头 5 个标签（`@//module/ @//description/ @//exports/ @//dependencies/ @//example/`）；
  每个导出函数 JSDoc 必须含 `@param/@returns/@sideEffects`（本项目最爱出「看着纯其实写 DOM」）；
  complexity ≤10、max-depth 3、单函数 ≤80 行、单文件 ≤300 行；>3 分支一律映射表/策略对象（11 处已列）。
- 顺带确认：`node` 会把带 import/export 的 `.js` 自动识别为 ESM（`test/sourceEmitter.test.mjs`
  直接 import `src/js/**/*.js` 且测试全绿即为证），所以 iframe 侧 ESM 模块可被 `node --test` 直接 import，
  不必改 `package.json` 的 type，也不必改扩展名。
