# 2026-10-22

## 前端统一样式重构（v1.18.0）

- 18 个 iframe 页面的 `<style>` 与全部 `style=""` 内联样式清空，样式统一进 `iframe/css/common.css`
  （470 条规则、约 66KB）。公共组件：工具栏 / 按钮三档 / 表单控件 / 表格 `.tbl` / 状态栏两型 /
  图例 / 卡片 / 弹窗 / 加载态；页面段落只写「和别处真的不一样」的规则。
- 关键坑与约定（已同步进 MEMORY.md）：
  - `.hidden` 必须放在 CSS 文件**最末尾**：页面段落里有 `display:grid/flex` 的元素（如 `#gridPreview`），
    同权重下靠顺序压制；又不能加 `!important`（JS 要写 `style.display` 覆盖它）。
  - 类名一旦被 JS 查询就不能改：`.sidebar-item`、`.view-container`、`.grid-row`、`.row-cell`、
    `.manual-input`、`.table-header .header-cell`、`.grid-item`、`.unit-option`、`.dpi-value-item`、
    `.preview-placeholder`、`.main-row`、`.details-row`、`.sort-icon`、`.sort-arrow` 等。
  - `CreateFootprint.js` 里 `querySelector('.container')` 已改 `.cf-form`（V3/V4 会清空整个表单换成
    「只支持 V2.2.45」提示，找不到容器会静默走进 catch）。
  - `status-bar` 默认必须是灰底（ImportBom 的 JS 会整串替换 `className`），蓝底用 `.accent`。
- 新增 `tools/layout-check.mjs` + `npm run check:layout`：按 `src/index.ts` 的 openPage 尺寸逐页实测
  溢出/裁切/按钮截断并截图。Chrome 窗口有最小尺寸（<500px 宽会被夹、矮窗口被压到 4px），
  所以测量必须走「harness 页面 + 精确尺寸 iframe」，不能直接 `--window-size` 当页面视口。
- 结果：`npm test` 124 全绿；18 页版式 0 溢出；页面冒烟与基线一致（OutPinNet 的 `pcb_Net.getAllNets`
  与 WorkingHours 的 0 尺寸 canvas 是 mock 缺口，重构前就有）。
- 产物 `build/dist/wolfblack-tool_v1.18.0.eext`（extension.json / package.json / CHANGELOG 已升版）。
