- 页面专属样式写回 18 个 HTML 的 `<style>`，删除 18 个独立 CSS 文件（git 中可回溯）。
- 教训（重要）：
  1. **不要把 `* { margin:0;padding:0;box-sizing }` 放进公共样式**。About 页依赖浏览器默认段落边距与 content-box，全局重置会让整页版式位移 → 该重置必须留在各页面。
  2. **`body` 只放 background/color，不要放 font-family/font-size**。否则会盖掉页面 `*{}` 上的字体设置（如 ImportQrcode 的 Consolas），并让默认 16px 的页面变小。
  3. **切分 CSS 声明不能用 `body.split(';')`**：`url('data:image/svg+xml;utf8,...')` 里的分号会被打断，导致图标消失、后续规则被吞。必须按「引号/括号深度」切分。
  4. **同名变量在不同页面语义可能不同**：About 的 `--bg-color` 是 `#252526`（面板），其它页面是 `#1e1e1e`（主背景）→ 需要按页覆盖映射。
  5. 变量重命名必须同时扫 HTML 内联 `style="...")` 与 JS 模板字符串。

## v1.17.5 测试样本自动化测试工具

需求：给 `测试样本/` 里各版本工程文件做一套**脱离 EDA** 的自动化测试，覆盖全部版本且全部通过。

**样本实测结论（写代码前必须先看这里，我第一版断言就踩了 3 个坑）**
- 三个样本：`Board_V2.2.45.epro`（zip，每文档一文件：`SHEET/uuid/id.esch`、`PCB/uuid.epcb`…）、
  `Board_V3.2.149.epro2` / `ProDoc_V4.1.78.epro2`（zip，`project2.json` + 单个 `.epru` 日志流，按 DOCHEAD 切文档）。
- 全部 LF 换行，无 CRLF。
- **V3/V4 存在缺行尾 `|` 的行**（BOARD 的 META），改写时必须原样保留 → 这是 `write.roundtrip` 用例的由来。
- **V2 有孤立的 `[]` 行**（EDA 写盘残留）→ 只能记 warn。
- **V2 FOOTPRINT 没有 HEAD 行**（SCH/PCB/SYMBOL 才有）→ "第二行必须 HEAD" 的断言最初误报 3 条。
- **V3/V4 内层字段是 `layerId` 而不是 `layer`**；V2 图元 layer 在数组下标 4 → 最初 `atom.layer` 空跑（假通过）。
- 样本里出现 **layer 45/46 = Inner31/Inner32**、**361 = Dielectric1**，都不在官方表里 → 补进 `pcbConstants`。
- ticket 在同一文档内**会重复**（V3 有 8 个文档重复）→ 不能断言唯一。

**工具结构**：`test/samples/{run.mjs, cases.mjs, lib/{loader,product,stats,report}.mjs, README.md}`
- 10 个用例：pkg.structure / pkg.version / doc.parse / doc.head / doc.id-unique / atom.ticket / atom.layer /
  write.roundtrip / write.trailing-pipe / plugin.layer-consts
- 关键设计：**用例断言打在产品代码上**（`WolfCommon.splitSourceLine/joinSourceLine`、`pcbConstants.isKnownLayer`），
  不是测试里另写一份解析器 → 为此把行切分/拼装抽到 common.js，并让 GenerateNet 复用（像素比对 5 页 0.000%）。
